# Inter Display

Official Inter Display Medium (500), SemiBold (600) and Bold (700), from https://github.com/rsms/inter/tree/master/docs/font-files.

Locally subset to Latin, Latin-1, general punctuation, the euro and trademark symbols, retaining OpenType layout features. SIL Open Font License included in OFL.txt.

Loaded with next/font/local. Headings use Bold display-specific outlines with tight tracking; body text continues to use Inter.
