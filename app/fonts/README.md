# Inter Display

Official Inter Display Medium (500) and SemiBold (600), from https://github.com/rsms/inter/tree/master/docs/font-files.

Locally subset to Latin, Latin-1, general punctuation, the euro and trademark symbols, retaining OpenType layout features. Both WOFF2 files together are approximately 55 KB. SIL Open Font License included in OFL.txt.

Loaded with next/font/local. Headings use these display-specific outlines; body text continues to use Inter. Existing letter spacing is preserved.
